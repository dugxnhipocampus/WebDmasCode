POWER-UPS TỐI THƯỢNG

Mỗi tính năng là một món đồ hiếm — rớt thẳng vào project của bạn, không cần farm thêm dependency.

KHIÊN TLS 1.3

Bắt tay TLS 1.3 mặc định, hỗ trợ cert pinning, mTLS hai chiều và tự tái sử dụng session ticket. Ổ khóa Locky không bao giờ ngủ.

httpmas.get(url, verify=True, http2=True)

handshake đang chạy… 41ms

TÚI ĐỒ 0 DEPENDENCY

0

Toàn bộ thư viện chỉ xây trên stdlib: ssl, socket, asyncio, json. Cài là chạy — không kéo theo cả vương quốc wheel.

SONG KIẾM ASYNC

AsyncClient sinh ra cho asyncio: connection pool, giới hạn concurrency, cancel giữa chừng không rớt socket.

async withpool=32await

TRÁI TIM RETRY

Exponential backoff + jitter, tự nhận diện 429 / 503 và đọc header Retry-After như một healer chuyên nghiệp.

DÒNG CHẢY STREAM

iter_chunks() kéo dữ liệu theo từng khối — tải file 10GB mà RAM vẫn phẳng như mặt hồ pixel.

XA LỘ HTTP/2 — 100 STREAM / 1 KẾT NỐI

Multiplex trên một kết nối TCP duy nhất, nén header HPACK, keep-alive mặc định. Tắc đường là khái niệm của thư viện khác.

# một dòng là xong
import httpmas

r = httpmas.get("https://api.github.com/zen", timeout=5)
print(r.status_code)   # 200
print(r.text)          # "Keep it logically awesome."
import asyncio, httpmas

async def main():
    async with httpmas.AsyncClient(pool=16) as cli:
        res = await cli.post("https://httpmas.dev/echo",
                             json={"hello": "pixel"})
        print(res.json())

asyncio.run(main())
with httpmas.stream("GET", "https://cdn.httpmas.dev/big.zip") as r:
    with open("big.zip", "wb") as f:
        for chunk in r.iter_chunks(65_536):
            f.write(chunk)   # RAM vẫn phẳng như mặt hồ
cli = httpmas.Client(
    http2=True,
    verify=True,                          # CA bundle hệ thống
    cert=("client.pem", "client.key"),   # mTLS hai chiều
    retries=httpmas.Retry(total=3, backoff=0.5, jitter=0.2),
    proxy="socks5://127.0.0.1:1080",
)
